---

## ✨ Key Features

- **Activity & Habit Logging:** Quickly record daily tasks, distraction logs, and time spent on non-productive activities.
- **Productivity Tracking:** Interactive UI elements to visualize focus time vs. procrastination time.
- **Dynamic DOM Manipulation:** Pure JavaScript logic handling state, task entries, and responsive UI updates.
- **Clean & Minimalist Design:** Simple, distraction-free user interface built with semantic HTML5 and custom CSS3.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Deployment:** GitHub Pages
